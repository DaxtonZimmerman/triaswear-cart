# TriasWear Shopping Cart

## Project Description

TriasWear Shopping Cart is a JavaScript shopping cart application based on the TriasWear clothing brand.

Users can browse products, add products to their cart, update quantities, remove products, and view their order total.

The cart is saved using localStorage so it stays saved when the page is refreshed.

## Completed Features

- Dynamic product rendering with JavaScript
- Add to Cart functionality
- Dynamic cart item count
- Shared cart state
- Increase and decrease item quantity
- Remove items from cart
- Item subtotals
- Order total calculation
- Shipping calculation
- localStorage persistence
- Reusable header
- JavaScript modules
- TriasWear product images

## How to Run

1. Open the project folder in VS Code.
2. Install the Live Server extension if needed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
